# Content attribution

Topic study pages contain generated adaptations or original factual summaries of their cited sources. Each page retains source titles, publishers, URLs, Wikipedia revision identifiers where available, retrieval metadata, and any verified license links. Multiple-source pages retain every listed reference. A source without a license label is a factual reference, not a claim that its text is openly licensed. Follow those page-level links for source attribution and applicable terms; a blanket license is not asserted for the combined corpus.

Original tournament questions and answers are retained with their tournament, round, question number, and school level. Bonus lead-ins and all three parts remain together. These texts are attributed to their original tournament sources; their inclusion here does not assert ownership or grant a new redistribution license.

Practice questions were generated and editorially revised from the topic descriptions, study content, and tournament questions. Their evidence references and original canonical answer names remain in the data. Some incorrect answer choices intentionally use invented titles or names.

The dataset was prepared using OpenAI models. The original import's generation and review artifacts are maintained separately. Research and review records for the GPT-6 Sol enrichment begun September 24, 2026 are in `research/topic-enrichment/2026-09-24/`; new overview and fact blocks retain the URLs supporting each block.

The later GPT-6 Luna API enrichment used one independent request per topic, with researcher self-checks and automatic format, citation, and research-trace checks. Response records for the 100-topic pilot and the subsequent 839-topic run are retained in `research/topic-enrichment/luna-pilot-2026-09-24/` and `research/topic-enrichment/luna-two-source-2026-09-24/`. Targeted, evidence-backed corrections were applied to normalized import copies. AWS signing parameters in web-search trace URLs were subsequently removed from 41 response records; the original and sanitized artifact hashes are recorded in `research/topic-enrichment/security-cleanup-2026-09-24.json`. Generated research content was not changed by that security cleanup. A limited 12-topic pilot sample received an independent factual audit; the full 939-topic set did not. Each accepted study block retains its supporting source URLs and page-level reference metadata without asserting an unverified source license.
